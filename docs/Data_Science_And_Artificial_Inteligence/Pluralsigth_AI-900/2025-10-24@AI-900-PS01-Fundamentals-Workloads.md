## Artificial Intelligence Overview

What is AI?

- Not magic
- Not androids
- copies behaviors of humans

### Parts of AI

#### Machine Learning

- How a machine can learn to make predictions or group things
- Foundation for most AI systems

How can a machine learn?

- Use data to train machine learning models to make predictions

#### Anomaly Detection

- Uses machine learning to analyze data over time and identify unusual changes
- Watches for trends and finds outliers in the data
- Anything that deviates from the standard pattern

#### Knowledge Mining

- Extracting information from large volumes of data

Instead of reading through documents, hand-written notes, etc., we can use knowledge mining to extract that data and
record it into a searchable knowledge base.

#### Computer Vision

This is the way AI can see the world through visual processing.

- Examine images and videos, and live cameras
- to do things like image classification, to classify images based on what's in them like cars.
- Object detection and facial recognition
- Extracting text from images

#### Narual Language Processing - NLP

- Voice assistants like Siri, Alexa
- Analyzes and interprets text
- automatically translate spoken or written text

#### Generative AI

- AI that can create "original" content such as text, images, and code!

### Uses for AI

#### Machine Learning

- Predicting walking time
- Forecasting Demand for products or services
- Classifying - if person is high risk or low risk for loans for example

#### Knowledge Mining

Let's say that you work for a company that does research of scientific data. Instead of reading document by document
and spending hours just sorting data by hand we can use **Knowledge Mining** to ingest those documents.

One thing to know is that Knowledge Mining is great for unstructured data, like PDF files, CSVs, HTML, etc.

Once that's done, we can use text recognition to pull out key phrases and key words.

Then publish to a searchable library or database which will be used as the knowledge base.

#### Anomaly Detection

- It can be used to detect fraudulent changes.
- It can be used to detect mechanical or hardware issues on machinery.

#### Computer Vision

- Facial Recognition
- Facial Analysis
- Recognizing Text in Images

#### Natural Language Processing - NLP

- You talk to the AI through Speech Recognition
- AI talks back to you through Speech Synthesis
- It is also used for translations

##### Content Moderation

- Analyze text, images for inapropriate content
- Jailbreak risk detection
- Scan AI generated text for protected material

#####

We can also use AI to personalize our applications and to help us make decisions.

#### Generative AI

We can talk to the AI by using normal language and then have it create something for us.
We can have AI give us something back in text form or natural language.
It can also generate images.
It can also create code in whatever language we like.

### Creating Responsible AI

#### Fairness

AI systems should treat all people fairly.
The problem is that data and people can have biases.

The idea is to limit biases in AI systems.
Make sure the application doesn't discriminate.

#### Reliability and Safety

Ensure that it can handle errors or values it doesn't expect.
It should operate as designed and should resist manipulation.

AI systems for self-driving vehicles or for prescribing medications need to be reliable and safe.

#### Privacy and Security

AI systems should be private and secure.
Secure data so no user data is leaked or disclosed.
Provide users with information and control in regards to how the system handles their data.

#### Accessibility

So that any user can have access to it.

#### Transparency

Users should be fully aware of how the system works and what the limitations are.

#### Accountability

People should be held accountable for AI systems.
AI systems should follow governance and frameworks.

### Exam Tips

#### How to use AI

- Know the use cases for each type of AI
  - Machine Learning: Predicting, forecasting, classifying
  - Knowledge mining: ingest data, pull our key words, publish to searchable location
  - Anomaly detection: To find unexpected behaviors, data. A credit card suddently being used in an unexpected location
  - Computer vision: facial recognition, recognizing texts in images.
  - Natural Language Processing: content moderation, sentiments, translations, scan for IPs

- Be able to differentiate between the different types of AI.

- Remember each of the 6 principles of responsible AI
- Be able to think of an example for each principle
- Understand how they differ from one another.

### Learning Check

1) You're building an AI application and you want to make sure that it doesn't discriminate based on gender, ethnicity,
disabilities, or any other factor. What principle of responsible AI are you following?

- [ ] Transparency
- [x] Fairness
- [ ] Reliability and Safety
- [ ] Accountability

> Correct! Fairness is about ensuring that AI systems treat all people fairly and avoid affecting certain groups of people in a negative way.

2) To build AI systems that empower all people no matter their physical abilities or disabilities, gender, race,
ethnicity, or anything else, which responsible AI principle are you following?

- [x] Inclusiveness
- [ ] Reliability and Safety
- [ ] Accountability
- [ ] Transparency

> Correct! Inclusiveness handles situations where the AI systems should empower all people and make the AI systems
available to everyone.
