# Common C# Interview Topics

## SOLID

They will ask about SOLID. Be ready to explain each principle. Also, be ready to show examples in C#.

## CRUD

Most C# jobs will involve CRUD. So you must be able to explain what that is and how it's done in C#.

## OOP

You will also be asked about Object Oriented Concepts. Be ready to explain and show examples.

## async/await

They might ask "What can you tell me about async/await". They are expecting you to explain that it frees up the thread,
but after that you can give more details.
