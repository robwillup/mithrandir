# Technical Books

Designing Data Intensive Applications: A comprehensive guide covering core principles of scalable, reliable, and maintainable systems, including data storage, retrieval, encoding, replication, partitioning, and consistency; considered the definitive book on distributed systems.

A Philosophy of Software Design: A concise book advocating for deep modules, careful information hiding, and comments as part of design, offering tactics to improve code clarity and team alignment; praised as a modern alternative to older classics like Clean Code.

The Pragmatic Programmer: A foundational text covering debugging, automation, career advice, and critical thinking, encouraging a pragmatic approach to software development and continuous improvement.

Clean Code: A goldmine of practical advice on writing readable, maintainable, and professional-grade software, emphasizing naming conventions, refactoring, and code quality.

Refactoring: A practical guide introducing over 70 techniques to systematically improve code design without changing functionality, with step-by-step instructions and examples; essential for enhancing codebase maintainability.

Site Reliability Engineering: The foundational SRE text from Google, covering SLIs/SLOs, error budgets, incident response, and automating operations, crucial for building and running reliable systems.

Accelerate: A research-backed book linking specific engineering practices to measurable outcomes like deployment frequency and lead time, providing an evidence-based framework for improving software delivery.

Team Topologies: A practical model for team design and interactions, defining team types and modes to align organizational structure with system architecture and improve flow.

The Phoenix Project: A novel-style book that teaches DevOps concepts through storytelling, illustrating continuous delivery, collaboration, and automation in a real-world context.

Code Complete: An all-encompassing resource on writing high-quality, bug-free code, covering design patterns, testing, debugging, and the entire software development lifecycle.
