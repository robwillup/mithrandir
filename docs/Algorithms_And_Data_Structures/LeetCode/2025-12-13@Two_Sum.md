# Two Sum

Understanding the more efficient algorithm that uses a hash map.

```csharp
public int[] TwoSum(int[] nums, int target)
{
    Dictionary<int, int> map = new();

    for (int i = 0; i < nums.Length; i++)
    {
        int complement = target - nums[i];

        if (map.ContainsKey(complement))
        {
            return new int[] { map[complement], i };
        }

        map[nums[i]] = i;
    }
    return new int[0]; // No solution found
}
```

Suppose the input array is [7, 8, 9]
Su ppose the target is 16.

---
1st:

complement = 16 - 7 = 9

does the map contain the key 9?
No because it's empty.

now map has the key and value:

7 :0

---

2nd


complement = 16 - 8 = 8

does the map contain the key 8?
No.

Now map has keys and values:

7:0
 8:1

---

3rd

complement = 16 - 9 = 7

does the map contain the key 7?
yes.

Return [7, 9]
