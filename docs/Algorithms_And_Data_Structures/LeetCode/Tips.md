# Tips for when studying in LeetCode

## Mistakes

### language

The language you choose can be a mistake. If the language itself is too complex, you had to spend time focusing on the
language rather than on the actual problem. This is the same for languages that are too verbose, like Java.

So Go and Python are strong candidates.

### Solving Random Problems

Another mistake is solving random questions.

You need to solve the problems in the correct order. The order does really matter.

When in doubt follow this roadmap:

neetcode.io/roadmap

### Wasting 14:45

If you cannot solve a problem in 45 minutes, stop. You will not be able to solve this even if you spend all day.
Go and search for help. Study the solution, identify the pattern.

### Not going back to review

You need to go back and review the problems.

For these complex algorithms to really sync in, you need repetition.
