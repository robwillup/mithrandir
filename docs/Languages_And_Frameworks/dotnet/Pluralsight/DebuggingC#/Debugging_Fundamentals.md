# Debugging Fundamentals

* Bug: Engineering term from 1800's. Mechanical malfunctions - used by Thomas Edison
* 1946: Used by Grace Hopper in Mark II - there was a moth in the relay
* A bug is a defect in the code.

Debugging is the process of identifying the cause of an error and correcting it.

Testing is the process of detecting errors during development.

Refactoring is the process of restructuring source code to improve its operation without
altering its functionality.

Diagnostics is instrumenting applications to gather data about its internal operation, after
it's been released.

## Defect Fundamentals

* Functional errors
* Security defects
* Syntax errors
* Logic errors
* Calculation errors
* Out-of-bounds bugs
* Compatibility defects
* System-level integration bugs
* Performance defects
* Usability defects
