# Object Oriented Programming

This is a programming paradigm that focuses on objects and classes rather than on functions and logic.

It is usually well suited for larger applications where you have to model a business logic.

It tends to be easier to maintain and reuse. 

## The Four Pillars of OO

### Encapsulation

- The code is written so that the information is contained inside of the object.
- Only certain information is exposed.
- Internal implementation is hidden inside of the class
- Internal data is hidden inside of the object.
- Avoids data corruption
- Private, protected, internal, public

### Abstraction

- taking the hard parts out and making it simpler to use
- only mechanisms useful for other objects are revealed
- Implementation is hidden
- Making changes becomes easier

### Inheritance

- Classes can reuse functionality from others
- Relation between classes
- Lower development time because of reusability

### Polymorphism

- Share behaviors but can be in more than one form
- Child can be used like its parent
- Correct method will be used based on execution
- Child can give a new meaning to a method
