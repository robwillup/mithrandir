# Go Language Specification

Go is a general purpose language and it was designed with systems programming in mind. Here,
`systems programming` is not referring to operating system kernels or low-level embedded systems.
These are "systems" just above operating systems, like cloud infrastructure, software the interacts closely with
the underlying system, such as the OS, network services, or infrastructure tools.

Go is strongly typed - this means it does not allow implicit type conversions in most cases.
Go is garbage-collected - this means that it takes care of free memory.
Go has explicit support for concurrent programming  - with goroutines

Go programs are constructed from packages - effecient management of dependencies.
