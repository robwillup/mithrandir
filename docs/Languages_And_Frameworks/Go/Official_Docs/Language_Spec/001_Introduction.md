# Introduction

> Go is a general-purpose language

This means Go can be used to program all sorts of applications. SQL and HTML are examples of languages that are not
general-purpose.

> Go was designed with systems programming in mind.

This means that Go was intended to be used for writing software that interacts closely with the operating system and
hardware, such as sytem utilities, servers, and backend services.

> Go is explicitly typed

This means that the type of variables must be known at compile time. So programmers directly specify the expected
data type.

> Go is garbage-collected

The language automatically manages memory by reclaiming space occupied by objects that are no longer in use, preventing
memory leaks and eliminating the need for manual memory management.

> Go has explicit support for concurrent programming

The language offers native ways to write code that runs concurrently, that is, in parallel.

> Go programs are contructed from packages

This is how Go manages dependencies.
