# Why Go?

## Why Create Go?

- Created in Google
- They saw challenges in C++ and Python
- They wanted efficient compilation
- They wanted efficient execution
- They wanted ease of programming

### Guiding Principles

- Simplicity as a core value
- Commitment to backward compatibility
- Made for concurrent, network enabled applications
- Holistic approach to solve common problems

### Languages Characteristics

- Strong, static type system
- C-inspired syntax*
- Garbage collected
- Fully compiled
- Rapic compilation
- Single binary output*
- Cross platform

### Primary Use Cases

- Cloud and network services
- Command-line interfaces
- Cloud infrastructure
  - Docker
  - Kubernetes
  - Terraform
