# Tutorial

## 1.2 Command-Line Arguments

The `os` package provides functions and other values for dealing with the operating system in a platform-independent
fashion. Command-line arguments are available to a program in a variable named `Args` that is part of the `os` package.

The variable `os.Args` is a slice of strings.

Think of a slice as a dynamically sized sequence `s` of array elements where individual elements can be accessed as
`s[i]` and a contiguous subsequence as `s[m:n]`. The number of elements is given by `len(s)`

By convention, we describe each package in a comment immediately preceding its package declaration; for a main package,
this comment is one or more complete sentences that describe the program as a whole.

If a variable is not explicitly initialized, it will be initialized with the zero value for the type, 0 for numeric
values and "" for strings.

When declaring a new variable, you should typically use the short variable declaration inside functions or the
declaration with `var s string` at the package level when the initial value does not matter.:wqa
